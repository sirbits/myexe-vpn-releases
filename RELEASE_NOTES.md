# MyExe VPN v1.0.0

First public release. **Experimental** - early software under active
development; expect rough edges and breaking changes between releases. Use at
your own risk.

## Highlights
- One-click **AUTO** mode: automatic server discovery, testing and failover.
- **USER** mode: run your own servers / imported subscriptions (VLESS, VMess,
  Trojan, Shadowsocks, Hysteria2, TUIC, SSH, WireGuard, SSR, Snell, and more).
- **System-wide tunnel** (TUN) with automatic system-proxy fallback.
- **Stealth** handshake and traffic shaping to survive deep-packet inspection.
- **Wi-Fi hotspot** sharing with a captive-portal login and per-device access.
- Block-direct / kill-switch, encrypted DNS and bridges.

## Install
Download `MyExe-VPN-Setup-1.0.0.exe` below and run it. SmartScreen may warn for
a new unsigned app - **More info → Run anyway**. Launch as **Administrator** for
the system-wide tunnel and the hotspot.
