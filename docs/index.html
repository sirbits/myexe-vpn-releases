What it does

One-click connect

AUTO mode discovers, tests and ranks working servers, then picks the fastest. No server list to manage.

Bring your own servers

USER mode runs your own configs or subscription links: VLESS, VMess, Trojan, Shadowsocks, Hysteria2, TUIC, SSH, WireGuard and more.

System-wide tunnel

Route all PC traffic through a TUN adapter - no per-app proxy setup. Falls back to a system proxy automatically.

Stealth built in

DPI-resistant handshake, TLS fragmentation and traffic shaping help the connection survive deep-packet inspection.

Share to your phone

Turn your PC into a Wi-Fi hotspot that shares the protected connection, with a captive-portal login and per-device access.

Safety controls

Block-direct / kill-switch so nothing leaks around the tunnel, plus optional bridges and encrypted DNS.

Install

  1. Download MyExe-VPN-Setup-<version>.exe from the Releases page.
  2. Run the installer. As a new, unsigned app, Windows SmartScreen may warn you - click More info → Run anyway.
  3. Launch MyExe VPN. For the system-wide tunnel and the hotspot, allow the Administrator prompt.
